# OpenDoge V1.1 migration

Goal: bring LainLab feat/opendoge model and exported policies into robot_lab with independent local assets and runnable Isaac Lab inference.

Design: keep legacy entry points intact; add OPENDOGE_V1_1_CFG and a separate ONNX observation adapter/replay script. Copy URDF, meshes, reference MJCF, four policy/checkpoint bundles and attribution from LainLab commit 7f6df34c67c455a80b9d296344a53e8a969cd765. Repair URDF mesh paths by providing the expected meshes directory. Native replay uses Isaac Lab/Newton, not mjlab.

Contract: leg-major FL/FR/RL/RR hip/thigh/calf order for observations AND actions (mjlab JointPositionAction resolves natural joint order, despite grouped actuator declarations). Stance [0,.8,-1.6] on left and [0,-.8,1.6] on right. PD 12/.5, armature .005, torque 6/6/9 Nm; dt .005, decimation 2, action scale .25, no action clipping. IMU linear velocity is at base offset [0,0,.03]. Flat/getup actor: linvel3, angvel3, gravity3, relative q12, dq12, previous action12, command3 =48, no extra scaling/history. ONNX owns observation normalization. Rough appends 165 height samples /5. Skills appends jump twist3, onehot4, phase sin/cos2; only jump advances phase (2.5s), command [sin,cos,left_ground].

Choices: separate replay avoids pretending mjlab checkpoints are directly loadable by robot_lab RSL-RL. Use URDF for the existing multi-backend articulation interface, retain MJCF as source reference. Rough replay initially restricted to an actual plane, where all 165 scan heights are analytically identical; uneven terrain and training environments are follow-on work. Replay validates exported-policy migration, not original training performance.
